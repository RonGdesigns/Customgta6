## M61 — The Black Box

Story purpose: recover a tactical command server from a visible wreck so the public evidence and next evacuation route have physical corroboration.

Treatment:
- Spawn/use a collision-tested accessible wreck and identifiable server case.
- Gohan performs the dive/access/copy/recovery.
- Ice holds off the demolition/recovery team.
- Ron holds the actual pickup craft.
- Start any scuttle countdown only after the wreck/server is discoverable, not while the player is still traveling.
- Mission ends only after the server/evidence and required brothers reach the pickup.
- Copies should be distributed/secured before the next high-risk operation so the crew is not carrying the only proof.

## M62 — Steel Horizon
