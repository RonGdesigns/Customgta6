2. INTERSTITIAL SYSTEMS: BETWEEN-MISSION MECHANICS
SAFEHOUSES, SPECIALIZED WORKBENCHES, AND AMBIENT ACTIVITY CYCLES
Across all three acts, players operate from dedicated safehouses: Ice's Canal Logistics Loft / Radar Bunker (ammunition reloading press for AP and
Incendiary rounds), Gohan's Little Seoul Studio / Dish Array (decryption server rack for disabling police speed cameras and radar nets), and Guess's
Burro Heights / McKenzie Airfield Chop Bay (hydraulic dyno lift for swapping military turbine engines into fleet vehicles).
When switching outside missions, characters engage in trade-specific ambient actions (Ice cleaning rifles or doing counter-surveillance; Gohan packet-
sniffing corporate Wi-Fi or testing drones; Guess tuning turbocharged engines or ditching patrol cars in narrow alleys). Weazel News bulletins and
encrypted group smartphone texts dynamically comment on recent mission fallout.

3. TECHNICAL MOD ENGINE: BLOODLINESCORE.DLL RUNTIME ARCHITECTURE
PRODUCTION C# IMPLEMENTATION ARCHITECTURE
The core framework compiles into
scripts/BloodlinesCore.dll
 referencing
ScriptHookVDotNet3.dll
 targeting .NET Framework 4.8. It
provides three shared singletons accessible to all mission assemblies:
BloodlinesSwitchManager:
 Controls real-time switching, native sky-cam aerial transitions (
START_PLAYER_SWITCH
), and companion protection
tethering.
BloodlinesAudioManager:
 Streams 44.1kHz 16-bit Mono WAV dialogue lines generated by ElevenLabs with synchronized speaker-color HUD subtitles.
BloodlinesCheckpointManager:
 Preserves stage numbers, restores character positions and health, purges destroyed wreckage, and respawns mission
vehicles without softlocks.
// Core C# Switch Implementation Signature (BloodlinesSwitchManager.cs)
public static void SwitchHero(HeroID targetHero)
{
    if (targetHero == ActiveHero) return;
    Ped currentPed = Game.Player.Character;
    Ped targetPed = (targetHero == HeroID.Ice) ? IcePed : (targetHero == HeroID.Gohan) ? GohanPed : GuessPed;
    if (targetPed != null && targetPed.Exists() && targetPed.IsAlive)
    {
        Function.Call(Hash.START_PLAYER_SWITCH, currentPed, targetPed, 0, 1);
        Game.Player.ChangeModel(targetPed.Model);
        currentPed.Task.FightAgainstHatedTargets(180f); // Relinquished hero fights as AI
        ActiveHero = targetHero;
        BloodlinesAudioManager.ShowSubtitle($"Switched to ~y~{ActiveHero.ToString().ToUpper()}~s~", 2000);
    }
}

TRACK 3: ELEVENLABS AUTOMATED BATCH VOICE SYNTHESIS SCRIPT
Below is the Python automation script to batch-generate all voice cues directly from this scripture via the ElevenLabs API into 44.1kHz 16-bit Mono WAV
format:
import os
import requests
ELEVENLABS_API_KEY = "YOUR_API_KEY"
OUTPUT_DIR = "scripts/Bloodlines/audio/"
os.makedirs(OUTPUT_DIR, exist_ok=True)
VOICE_PROFILES = {
    "ICE":   {"voice_id": "EXAVITQu4vr4xnSDxMaL", "stability": 0.65, "similarity_boost": 0.85},
    "GOHAN": {"voice_id": "ErXwobaYiN019PkySvjV", "stability": 0.50, "similarity_boost": 0.80},
    "GUESS": {"voice_id": "VR6AewLTigWG4xSOukaG", "stability": 0.45, "similarity_boost": 0.75}
}
def generate_voice_line(cue_id, speaker, text):
    profile = VOICE_PROFILES.get(speaker.upper(), VOICE_PROFILES["ICE"])
    url = f"https://api.elevenlabs.io/v1/text-to-speech/{profile['voice_id']}"
    headers = {"xi-api-key": ELEVENLABS_API_KEY, "Content-Type": "application/json"}
    payload = {
        "text": text,
        "model_id": "eleven_monolingual_v1",
        "voice_settings": {"stability": profile["stability"], "similarity_boost": profile["similarity_boost"]}
    }
    response = requests.post(url, json=payload, headers=headers)
    if response.status_code == 200:
        with open(os.path.join(OUTPUT_DIR, f"{cue_id}.wav"), "wb") as f:
            f.write(response.content)
        print(f"Generated: {cue_id}.wav")
