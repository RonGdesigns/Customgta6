# Agent instructions

The instructions for this repository live in **`CLAUDE.md`**. Read that.

This file exists because some tools look for `AGENTS.md` by convention. It deliberately
holds no rules of its own: it was created as a copy of `CLAUDE.md`, and was already
forty-seven lines behind it the day it was written. Two instruction files drift, and the
one an agent happens to open decides which contracts it knows about.

If a rule belongs to this project, it goes in `CLAUDE.md`.
